# James Lu Reading & Writing practice

Independent study companion following the **Reading Comprehension Course** and **Grammar Mastery** in [James Lu's Skool classroom](https://www.skool.com/sat/classroom).

The Skool lessons set the sequence. Long lessons are split into study segments, with Khan Academy worked examples, original notes, and original practice within each lesson. The separate punctuation library is an optional supplement, not a Skool course lesson.

- 17 study steps and a six-hour route (340 study minutes and 20 break minutes).
- 182 original questions, including 52 new challenges.
- 17-question warm-up, 138 lesson questions, and a reserved 27-question mixed checkpoint.
- Per-question and per-set resets with undo, saved answers, review notes, and local profiles with backup import/export.
- Videos do not autoplay. YouTube and native Khan video players start muted; Loom lessons require an explicit play action.

Open `index.html` through a static web server. No installation, account server, or database is required. GitHub Pages deploys the root of `main`.

Progress is stored in this browser on the `shloksheth.github.io` origin, shared with the original math companion. Local profiles are not secure accounts or cloud sync. Back up important progress through the profile menu.

Practice, passages, notes, and data are independently authored educational examples. Difficulty labels are author estimates, not official College Board calibrations. The site is not endorsed by James Lu, Khan Academy, or College Board. Khan videos are embedded unmodified from their official CDN with individual source and license attribution. James videos are embedded from their original hosts; no source videos are copied into this repository.
